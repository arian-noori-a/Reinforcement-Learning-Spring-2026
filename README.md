# Reinforcement Learning — Spring 2026

Practical assignments for **Reinforcement Learning**, implemented mainly with Python, PyTorch, and Gymnasium.

## Contents

| Homework | Topics |
|---|---|
| **HW1** | DQN, Double DQN, Dueling DQN, Prioritized Experience Replay, and a Half-Rainbow combination |
| **HW2** | REINFORCE with variance-reduction techniques and Natural Policy Gradient |
| **HW3** | Deterministic Policy Gradient, DDPG, and TD3 for continuous control |
| **HW4** | Dyna-Q, prioritized sweeping, Monte Carlo Tree Search, and MuZero-style search |
| **HW5** | Contextual bandits, LinUCB/NeuralUCB, safe exploration, calibration, and offline policy evaluation |
| **HW6** | Deep exploration with Random Network Distillation and Bootstrapped DQN on DeepSea |
| **HW7** | Offline RL with DDPG+BC and imitation learning with Behavior Cloning, DAgger, and GAIL |
| **HW8** | Multi-agent RL and game theory, MADDPG/MAPPO, and meta-RL with MAML, RL2, and VariBAD |
